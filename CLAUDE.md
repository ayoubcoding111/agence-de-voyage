# Project: Fancyellow homepage

Before any design or content change, read `DESIGN.md` and follow it: colours, type scale (rem sizes, em tracking), layout grid, components, photo rules and motion are all defined there. Keep new work consistent with it, and update `DESIGN.md` when a design decision changes.

- Dev server: `npm run dev` (http://localhost:5173). Build: `npm run build`.
- Real client content only (Fancyellow, fancyalgeria.com). Never invent facts, reviews or staff.
- Photos: free-licensed real Algerian photos, credited in `CREDITS.md`, resized for the web.
- Never name the reference site in public files or commits.
- Repo: private GitHub `fancyellow-site`; commit and push when asked.
